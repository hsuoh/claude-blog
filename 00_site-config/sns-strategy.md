## 前提・基本方針

### 目的
- 薬剤師ユーザーと広くつながり、コミュニティの中心的存在になる
- 調剤報酬改定・大手薬局決算・業界ニュースなど有益な情報を即時発信する
- ブログ（pharmirai.com）への流入導線を作る

### 絶対に守るルール
- **批判禁止**: 特定の企業・個人・制度への批判・否定的コメントは絶対にしない
- **規約遵守**: Xの利用規約・ポリシーを常に遵守する
- **転職煽り禁止**: ブログと同様、感情に訴えて転職を煽る投稿はしない
- **一次情報尊重**: 厚生労働省・IR資料など公式ソースに基づいた情報のみ発信する

### ターゲット
- 20〜30代の病院・調剤薬局・ドラッグストア勤務薬剤師
- 年収・転職・将来性に関心のある薬剤師
- 調剤報酬改定の動向を追っている薬剤師

## コンテンツ設計（投稿の型）

### 投稿カテゴリ（ピラー）

| カテゴリ | 内容 | 頻度 | ハッシュタグ |
|---|---|---|---|
| 📊 決算分析 | 大手薬局の決算を分かりやすく解説 | 四半期ごと（決算発表後） | #薬局決算 #調剤薬局 |
| 📋 報酬改定速報 | 改定内容と収益・年収への影響 | 改定時・随時 | #調剤報酬改定 #薬剤師 |
| 💰 年収解説 | 職種別年収の収益構造からの分析 | 週1〜2回 | #薬剤師年収 #薬剤師転職 |
| 📰 業界ニュース | 薬局業界の再編・M&A・制度変更 | 週2〜3回 | #薬局 #薬剤師 |
| 🔗 記事紹介 | ブログ記事の要点をスレッドで紹介 | 記事公開時 | #薬剤師 |
| 💡 ミニ知識 | 調剤報酬の仕組み・用語解説 | 週1〜2回 | #薬剤師勉強 |

### 投稿の型（テンプレート）

#### 型①：データ・数字で始まる投稿
```
【○○の年収、実は△△で決まっている】

・調剤薬局の売上の約○○%が調剤報酬
・薬剤師1人あたりの生産性は月○○万円
・管理薬剤師手当の相場は月○〜○万円

つまり薬剤師の年収は「薬局の売上規模」と「点数の取り方」で決まる

詳しい仕組みはブログで↓
pharmirai.com/...
```

#### 型②：ニュース解説投稿
```
【○○ニュース｜薬剤師への影響は？】

（ニュース概要を1〜2行で）

収益構造から考えると：
・○○という影響がある
・特に△△の薬剤師は注意

詳しい分析はブログで▶ pharmirai.com
```

#### 型③：Q&A形式
```
Q. 病院薬剤師はなぜ給料が安いの？

A. 病院の薬剤師は「保険点数」ではなく「病院の経営判断」で給与が決まるから

病院は薬剤師を「コストセンター」として見ているため、
調剤薬局と比べると収益への貢献度が見えにくい

→ 続きはブログで解説中
```

#### 型④：スレッド（長文解説）
```
【決算解説スレッド】
○○薬局（証券コード：●●●●）の○期決算を分析します🧵

① 売上・利益の概要
② 調剤点数への依存度
③ 薬剤師一人当たり収益
④ 年収への影響試算
⑤ 今後の見通し

順番に解説します↓
```

## 0フォロワーからの成長戦略

### フェーズ1（0〜100フォロワー）：基盤作り
**期間目安**: 1〜2ヶ月

- プロフィールを徹底的に最適化する（固定ツイート・bio・画像）
- 薬剤師コミュニティの主要アカウントをフォローする（薬剤師系インフルエンサー・関連団体）
- 関連ハッシュタグ（`#薬剤師` `#調剤薬局` `#薬剤師転職`）で検索し、積極的にリプ・いいねを行う
- 質の高い投稿を週3〜5本コンスタントに続ける
- 他の薬剤師アカウントの投稿に有益なコメントをする（スパムにならない範囲で）

**目標**: フォロワー100人・インプレッション累計5,000超

### フェーズ2（100〜500フォロワー）：認知拡大
**期間目安**: 2〜4ヶ月

- スレッド投稿を月1〜2本作成する（拡散されやすい）
- 決算シーズン（4月・6月・8月・11月）に合わせて分析投稿を出す
- 調剤報酬改定のタイミングで速報投稿を出す（タイムリーさが重要）
- ブログ記事とセットで投稿する（記事→ツイートの連携）

**目標**: フォロワー500人・月間インプレッション5万超

### フェーズ3（500〜1000フォロワー）：コミュニティ化
**期間目安**: 4〜8ヶ月

- フォロワーからの質問に積極的に回答する
- アンケート機能を活用してエンゲージメントを高める
- プロモーション（アフィリエイト）をさりげなく開始（記事20本公開後）

**目標**: フォロワー1,000人達成・ブログへの月間流入100PV以上

## ブログとの連携フロー

### 記事公開時の投稿フロー
```
記事公開
↓
Claudeが記事の要点を3〜5点で抽出
↓
SNS投稿文（ツイート）を作成（型①or③）
↓
PMが確認・修正
↓
Xに投稿
↓
固定ツイート更新（必要に応じて）
```

### ニュース発信フロー
```
厚労省・IR資料・業界ニュースサイトで情報収集
↓
Claudeが要点を整理（収益・年収への影響を中心に）
↓
SNS投稿文を作成
↓
PMが確認・投稿
```

### 週次ルーティン
```
毎週月曜日:
  └ Claudeに「今週の薬剤師業界ニュース」をリサーチ依頼
  └ 週間投稿スケジュールを確認・調整

決算シーズン（四半期ごと）:
  └ Claudeに「○○社決算分析」をリサーチ・投稿文作成依頼
  └ 詳細はブログ記事としても展開
```

## Claudeへの標準依頼テンプレート（SNS版）

### H. SNS投稿文作成依頼
```
【SNS投稿文作成依頼】
テーマ: [テーマ or ニュースURL]
投稿の型: [①データ / ②ニュース解説 / ③Q&A / ④スレッド]
ターゲット: 薬剤師全般 / [病院 / 調剤薬局 / DS]薬剤師寄り

制約:
- 批判・ネガティブな内容は含めない
- Xの規約に反する内容は含めない
- 転職を煽る表現は使わない
- ハッシュタグは末尾に2〜3個
- 280文字以内（スレッドの場合はその旨明記）

出力:
- 投稿文（すぐにコピペできる形で）
- 補足メモ（意図・注意点）
```

### I. 週次ニュースまとめ依頼
```
【週次ニュースリサーチ依頼】
対象期間: [今週の日付範囲]

以下をリサーチして薬剤師目線でまとめてください:
1. 調剤報酬・制度関連のニュース（厚労省・日薬等）
2. 大手薬局チェーンの動向（決算・M&A・新施策）
3. 薬剤師需給・採用市場の動向
4. その他薬剤師に関係する業界ニュース

各ニュースについて:
- 概要（1〜2行）
- 薬剤師の年収・キャリアへの影響
- SNS投稿に使えるか（◎/○/△）

投稿に使えるもの（◎/○）についてはSNS投稿文案も作成してください。
```
